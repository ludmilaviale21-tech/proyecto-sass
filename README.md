# Proyecto SASS

Proyecto realizado para aprender el uso de Git, GitHub y SASS.

## Herramientas utilizadas

- Git
- GitHub
- SASS
- Visual Studio Code

## Características del proyecto

El proyecto utiliza:

- Variables de SASS.
- Anidamiento de estilos.
- Un mixin reutilizable.
- CSS compilado desde SASS.

## Compilación

El archivo SASS se compiló utilizando:

sass sass/estilos.scss css/estilos.css
