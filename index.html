Git, GitHub y SASS

Conceptos, diferencias y aplicación en un proyecto web

¿Qué es Git?

Git es un sistema de control de versiones que permite registrar los cambios realizados en un proyecto. De esta manera, podemos guardar diferentes versiones de nuestros archivos y volver a una versión anterior si es necesario.

¿Qué es GitHub?

GitHub es una plataforma que permite almacenar y compartir repositorios de proyectos utilizando Git. También facilita el trabajo colaborativo y permite acceder a los proyectos desde Internet.

¿Qué es SASS?

SASS es un preprocesador de CSS que permite escribir estilos de una manera más organizada, reutilizable y fácil de mantener. Luego, el código SASS se compila y se transforma en CSS.

Diferencias entre Git, GitHub y SASS

Git

Se utiliza para controlar y registrar las versiones de un proyecto.

GitHub

Es una plataforma online donde podemos almacenar, compartir y trabajar con repositorios Git.

SASS

Se utiliza para crear CSS de forma más organizada mediante variables, anidamiento, mixins y otras herramientas.

¿Cómo se relacionan?

Git, GitHub y SASS cumplen funciones diferentes, pero pueden utilizarse juntos en un mismo proyecto web. SASS permite organizar y escribir los estilos, Git permite registrar los cambios realizados y GitHub permite almacenar y compartir el proyecto en Internet.

Características de SASS utilizadas

Variables

Permiten guardar valores, como colores, para poder reutilizarlos en diferentes partes del código.

Nesting o anidamiento

Permite organizar los estilos de elementos relacionados dentro de otros selectores.

Mixin

Permite crear un conjunto de estilos reutilizables. En este proyecto se utilizó para centrar elementos.

Compilación

El archivo estilos.scss se transforma en estilos.css para que el navegador pueda interpretar los estilos.

Proceso realizado

  1. Se creó la estructura inicial del proyecto.
  2. Se creó el archivo estilos.scss.
  3. Se agregaron variables, nesting y un mixin.
  4. Se compiló SASS para generar el archivo estilos.css.
  5. Se utilizó Git para registrar los cambios mediante commits.
  6. Se creó y conectó el repositorio con GitHub.
  7. Se subió el proyecto a GitHub.

Conclusión

Git permite controlar las versiones de un proyecto, GitHub permite almacenar y compartir el repositorio y SASS facilita la organización de los estilos. El uso conjunto de estas herramientas permite desarrollar proyectos web de una manera más ordenada y mantener un registro de los cambios realizados.
